Создай сайт для самостоятельного обучения статистике.

Идея:
"Statistics for beginners" - сайт с уроками, разбитыми на темы с возможностью отбора по темам.

Сделай:
- уроки исключительно из файлов в папке: "E:\Statistics One";
- создай карточки для каждой лекции с ссылками на подходящие видеофайлы .mp4, файлы .pdf  и .txt;
- создай карточки для каждой темы с ссылками на карточки лекций;
- создай карточку для содержимого всего курса с ссылками на карточки тем;
- добать фильтр по темам.

Стиль:
- классический, но оригинальный;
- добавь темный фон, базовые цвета: бордовый и сине-зеленый, салатный, плавные переходы.

Технически:
- Python, Flask, HTML, CSS, JavaScript;
- files: app.py, content.json, index.html, style.css, script.js;
- запуск через python app.py;
- сайт должен отлично выглядеть как на десктопе, так и на мобильных устройствах.
